Bash Scripts

Scripts are the worker bees of VibeCrew — small bash programs that do the actual mechanical work. While agents think and make decisions, scripts create files, update project state, calculate scores, and send notifications. They run in milliseconds and always produce the same result for the same input.

■
What they are

Deterministic bash scripts organized by function: core lifecycle, feature management, quality scoring, project analysis, documentation, gamification, and state management. Agents never write state files directly — all mutations go through scripts.

✓
What problem they solve

AI token cost scales with complexity. By offloading mechanical tasks (JSON manipulation, git operations, file formatting) to scripts, VibeCrew keeps AI focused on decisions while scripts handle bookkeeping at zero token cost. Scripts also guarantee consistency — state mutations are atomic and predictable.

Core Lifecycle

Scripts that run during session startup and completion.

ScriptCalled ByWhat It Does
session-startup.shHookEnvironment check, terminal detection, state loading, and workflow routing on every session start.
quality-gate.shHookRuns typecheck, lint, and build on modified files at task completion. Blocks on failure.
statusline.shHookUpdates the terminal status bar with current feature, phase, and Vibe Score.
notify.shHookSends native OS notifications for permission stalls, completions, and errors.

Feature Management

Scripts that manage the feature lifecycle and backlog.

ScriptCalled ByWhat It Does
update-backlog.shAgent / SkillAdds, updates, or moves features in backlog.json. Manages Kanban column transitions.
complete-phase.shAgent / SkillMarks a development phase as done and advances to the next phase in the 6-phase cycle.
git-branch-create.shAgentCreates a feature branch with consistent naming: feat/<feature-name>.
create-checkpoint.shAgentCreates a git tag checkpoint before risky operations so you can roll back with /undo.

Quality & Scoring

Scripts that calculate Vibe Scores and analyze quality.

ScriptCalled ByWhat It Does
calculate-vibe-score.shAgentComputes the session's Vibe Score (0–130) based on deductions and bonuses across quality dimensions.
aggregate-scores.shAgentAggregates Vibe Scores across sessions for trend analysis and Performance Coach input.
analyze-test-gaps.shAgentCompares modified source files against test coverage to identify untested code paths.
apply-mutation.shAgentApplies Performance Coach CLAUDE.md mutation proposals after user approval.

Project Analysis

Scripts that analyze the codebase and extract patterns.

ScriptCalled ByWhat It Does
detect-conventions.shAgentScans the codebase for naming conventions, file patterns, and code style to populate CLAUDE.md.
extract-design-system.shAgentExtracts CSS tokens, color palette, typography, and spacing from existing stylesheets.
detect-secrets.shAgentScans for accidentally committed secrets, API keys, and credentials.
scan-dependencies.shAgentAudits dependencies for known vulnerabilities and license compliance issues.

State & Config

Scripts that manage the .vibecrew/ runtime state.

ScriptCalled ByWhat It Does
init-vibecrew-state.shSkillCreates the initial .vibecrew/ directory structure and default JSON files during /setup.
migrate-state.shSkillMigrates state files between VibeCrew versions when schemas change.
generate-handoff.shSkillCreates a structured context transfer document for cross-session continuity.
detect-terminal.shSkillDetects terminal type (Warp, iTerm2, VS Code, etc.) and configures notification and deep-link support.

Agent Infrastructure

Scripts that manage agent identity, memory, expertise, and per-project overrides.

ScriptCalled ByWhat It Does
agent-memory-read.shAgentReads persistent per-agent memory from .vibecrew/memory/<agent>/<domain>.jsonl.
agent-memory-write.shAgentAppends entries to agent memory with TTL-based auto-pruning.
expertise-read.sh / expertise-write.shAgentReads/writes agent expertise records in .vibecrew/expertise/.
expertise-sync-learnings.shAgentSyncs session learnings into expertise records for cross-session improvement.
register-agent.sh / deregister-agent.shHookRegisters or deregisters an agent with the session tracking system.
load-agent-with-overrides.shHookLoads an agent prompt with per-project overrides merged from .vibecrew/agent-overrides/.
collect-agent-metrics.shAgentCollects agent performance metrics (tokens, cost, duration) during /wrap.

ScriptCalled ByWhat It Does

collect-erosion-metrics.shAgentCollects current erosion metrics for comparison against baselines.

ScriptCalled ByWhat It Does

ScriptCalled ByWhat It Does

inject-analysis.shHook / AgentInjects /onboard analysis docs (stack, architecture, conventions, gaps) into context.
prepare-feature-context.shSkillAssembles the full context bundle for Agent-delegated feature execution.
compact-reinject.shHookRe-injects fresh project state and architecture after /compact.
check-analysis-staleness.shHookChecks if /onboard analysis docs are stale and need refreshing.
generate-analysis-docs.shAgentGenerates the 4 analysis markdown files during /onboard.

Shared Libraries (scripts/lib/)

Reusable functions sourced by other scripts. Not called directly.

LibraryWhat It Provides
atomic-write.shAtomic file writes with temp-file-then-rename to prevent corruption.
lock.shAdvisory locking with stale-lock detection and cleanup.
agent-identity.shAgent identification helpers (name, model, session ID).
git-provider.shAbstraction layer for GitHub vs GitLab operations.
error-log.shStructured error logging and reporting.
compat.shCross-platform compatibility shims (macOS vs Linux).
drift-classify.shClassification helpers for documentation drift severity.
dual-write.shWrites to both local state and telemetry simultaneously.
expertise-id.shGenerates stable IDs for expertise records.
