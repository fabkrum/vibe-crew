Personalization

User Profile & Personalization

Most AI coding tools treat every user the same. A non-technical founder gets the same commit messages and unexplained technical decisions as a senior developer. Beginners feel overwhelmed. Experienced developers find the output too verbose. VibeCrew solves this with an adaptive profile system.

Getting Started

Run /profile after setup. You can answer 8 quick questions (~2 minutes) or pick a preset:

⚙

Builder

For developers. Full autonomy, minimal output, no gamification. VibeCrew stays out of your way and just builds.

★

Explorer

For learners. Collaborative mode, detailed explanations, full gamification. Every step is a teaching moment.

✎

Founder

For non-technical users. Checkpoint approvals, standard output, light gamification. You stay in control without needing to read code.

You can also skip the interview entirely and use balanced defaults. Run /profile anytime to change your preferences.

Evolving Over Time

Your profile isn’t locked in. As you gain experience, your needs change. A learner who started with educational verbosity and collaborative autonomy might switch to standard and checkpoints after a few projects. A founder who initially needed walkthrough PRs might move to summary PRs once they’re comfortable with the process.

Run /profile again at any point to update your preferences. The system shows your current settings, lets you change any dimension, and immediately adapts every agent to match. You always have exactly the system that works best for you right now.

Profile Hint
If you haven’t completed the profile interview yet, VibeCrew will gently remind you on session start: “Tip: Run /profile to personalize VibeCrew to your workflow.” Dismiss it if you prefer the defaults.
Progression

Gamification System

VibeCrew includes a persistent progression layer that motivates across sessions and teaches vibe-coding skills over time. Built on three principles: artifacts over actions (rewards map to real outputs), teaching over tracking (every mechanic helps you improve), and sustainable over addictive (grace periods, opt-in challenges, no toxic leaderboards).

The gamification system uses the existing Vibe Score as its primary data source. Every metric flows from real work artifacts — shipped features, passing tests, clean sessions — not arbitrary actions.

How it integrates
The gamification pipeline runs automatically at the end of every /wrap. Six scripts execute sequentially: award XP, check badges, update streak, distribute skill XP, update challenges, and check level-ups. The /achievements command shows a compact CLI summary, and the VitePress dashboard provides the full visual experience.

Streaks

Streaks track consecutive days of coding, designed to be encouraging rather than punitive.

  • Increment on calendar days where /wrap is run
  • Weekend auto-grace: Saturdays and Sundays don’t break streaks and don’t consume grace credits
  • 2 grace days/month: Missing one weekday preserves the streak (resets on the 1st)
  • No penalty for broken streaks — the counter resets to 0 but no XP is lost
  • Streak reminders are opt-in (disabled by default in config.json)
Sustainable by design
The weekend auto-grace and monthly grace days ensure that taking time off doesn’t feel punishing. The system celebrates consistency without demanding it — a broken streak is just a number, not a loss.

Quizzes (/quiz)

Short (3–5 question) knowledge checks delivered interactively in the CLI. Each question shows the answer and an educational explanation regardless of correctness. Unlocks at Level 3.

Triggering quizzes

  1. Explicit: /quiz or /quiz context-management-101
  2. Contextual: Performance Coach suggests a relevant quiz after /wrap when it detects a specific anti-pattern (e.g., low cache → context-management-101)
  3. Periodic: Session Startup suggests an overdue quiz (never forces it)

XP: +5 per correct answer (modest — cannot substitute for real work XP).

Configuration

All gamification settings live in .vibecrew/config.json:

"gamification": {
  "enabled": true,            // Master toggle
  "streak_reminders": false,  // Opt-in daily reminders
  "quiz_frequency": "weekly", // How often quizzes are suggested
  "show_xp_in_status": true   // Show XP in /status output
}

Set "enabled": false to suppress all gamification output. The Vibe Score and Performance Coach continue to operate independently.

Team features (optional, non-competitive)

  • Aggregated team stats (average score trend, total features shipped)
  • Team badges for collective achievements (“Team ships 10 features”)
  • No individual rankings or comparisons — the system is collaborative, not competitive
