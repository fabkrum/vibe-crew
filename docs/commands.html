Slash Commands Reference

All 31 VibeCrew slash commands with their agents, tier requirements, and descriptions. Use the filter tabs or search to find what you need.

Command Category Agent(s) Tier Purpose
/setup Setup Session Startup Any Verify dependencies, detect terminal, initialize .vibecrew/
/new-project Setup Orchestrator, Stack Scout, Builder, Opponent 1 7-step foundation: VISION, design system, TDR, roadmap, architecture diagrams, CLAUDE.md, commit
/onboard Setup Code Auditor 1 Existing project analysis, convention extraction, CLAUDE.md generation
/plan-features Planning Orchestrator 2 Define backlog specs: problem statement, acceptance criteria, priority, complexity, dependencies
/idea "text" Planning None (script only) Any 1-line capture to backlog.json with status "unplanned". Zero context cost
/status Planning None (script only) Any Full project dashboard: foundation, backlog, active feature, recent scores
/new-feature "name" Development Builder 2 Branch creation, checkpoint, 6-phase tracking, WIP limit enforcement
/run-backlog Development Builder, Verifier 2 Auto-execute features by priority. Stops on failure for human review
/check Development Verifier 2 Run tests + build + lint + type-check without modifying code
/simplify Quality Code Simplifier 2 Read-only analysis: dead code, abstractions, API surface. You approve each change
/apply-simplifications Quality Code Simplifier 2 Apply approved changes from /simplify analysis
/reconsider Quality Opponent Processor 1 Devil's advocate analysis of TDR decisions, debate matrices, risk assessments
/replay Quality None (script only) 2 Create, list, or apply workflow templates from high-scoring sessions
/cost Safety None (script only) Any Real-time cost dashboard: session, daily, weekly, monthly aggregates + pricing table
/undo Safety None (script only) Any List checkpoints and recent commits, safely revert or reset
/audit Safety Security Auditor 2 OWASP Top 10 scan: injection, auth, XSS, secrets, dependencies
/heal Safety CI Healer 2 Fetch CI logs, diagnose failure, apply fix (max 3 attempts)
/wrap Session Verifier, Performance Coach, Doc Generator 2 Quality gate, Vibe Score, coaching, commit, session log, gamification pipeline
/handoff Session None (script only) 2 Generate structured context transfer document for next session
/recover-state Session None (script only) Any Clear lock files and repair corrupted JSON state
/achievements Gamification None (script only) Any Level, badges, skill tree, streaks, challenges + visual dashboard link
/quiz Gamification None (inline) Any Interactive knowledge checks with educational explanations (Level 3+)
/review Testing & Review Code Reviewer 2 Code review against feature spec, TDR compliance, conventions. Findings by severity
/tdd Testing & Review Verifier 2 Test-driven development cycle: write failing test, implement, verify green
/e2e Testing & Review Verifier 2 Generate Playwright E2E tests with Page Object Model
/perf-test Testing & Review Verifier 2 Generate k6 load/stress/spike/soak test suites
/a11y Testing & Review Verifier 2 WCAG 2.1 AA accessibility audit via axe-core
/debug Development Builder 2 Structured debugging workflow with hypothesis testing
/release Session Doc Generator 2 Generate release notes from git history and session logs
/profile Setup None (inline) Any 8-question interview or preset selection for personalization
/fix-issue <number> Development Builder, Verifier, Code Reviewer 2 Fix an issue (GitHub/GitLab) — fetch, diagnose, implement, test, PR/MR with auto-close
/sync-issues --label <name> --limit <n> Planning None (script only) 2 Import open issues by label into the VibeCrew backlog
/system-review Quality System Reviewer Any Plugin meta-analysis, cross-project telemetry, ecosystem research
