Skills Reference

Every slash command maps to a skill — a SKILL.md file in the skills/ directory. Skills range from zero-cost script-only operations (like /idea and /status) to complex multi-agent orchestrations (like /new-project and /wrap). Use the category filters to browse all available skills.

■
What they are

SKILL.md files with YAML frontmatter (name, description, arguments) and a markdown body defining the full workflow: preconditions, steps, error handling, and agent routing. Some skills are script-only (zero tokens), others spin up single or multiple agents.

✓
What problem they solve

Skills turn complex multi-step workflows into single commands. Instead of writing a detailed prompt for "run tests, calculate score, generate docs, commit, and log session," you type /wrap and the skill definition handles every step, error path, and agent handoff.

Modern Skill Patterns

VibeCrew skills leverage advanced Claude Code features for better autocomplete, cost optimization, tool scoping, and native subagent isolation.

Dynamic Injection (! Backtick)

Skills can pre-load data at load time using ! backtick syntax. The shell command runs before Claude sees the prompt, eliminating the first “read state” turn and saving tokens.

Native Argument Substitution

Skills use $ARGUMENTS and $0 for native argument parsing instead of manual extraction steps. $0 captures the first argument, $ARGUMENTS captures the full argument string.

Forked Skills

Four analysis skills use context: fork with a dedicated agent: to run in native subagent isolation. The forked agent produces formatted output directly and returns results to the main session.

Intent-Based Triggering

You don't need to memorize all 38 commands. VibeCrew includes an intent detection layer that matches natural language to the right skill. For example, saying “fix a bug” suggests /fix-issue, and “check quality” suggests /check. Intent detection runs automatically during session startup and when the Orchestrator processes your requests.

The full mapping is defined in templates/intent-map.md and covers all core workflows: project setup, planning, development, quality, session management, CI/CD, analysis, and gamification. Slash commands remain the primary interface — intent detection is a convenience layer for discoverability.
