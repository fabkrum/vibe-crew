The Vision

You describe it. VibeCrew builds it right.

You have an idea — a SaaS product, a marketplace, a tool. VibeCrew makes sure what you build is production-ready: accessible, performant, designed to convert. No framework expertise. No best practices to memorize. Just describe what you want.

Why this exists

Born from painful experience. Before building this system, the creator tried vibe-coding without a plan — wrong tech stack three features deep, context windows filling mid-feature, token bills from re-explaining context, output that looked fine in demos but fell apart in production.

VibeCrew encodes every one of those lessons into an automated system, so you don’t have to learn them the hard way.

Work on everything at once

Picture this — you’re planning the next feature for Project A while VibeCrew is coding Project B and running tests on Project C. Three projects, all progressing. When an agent finishes, needs a decision, or hits a problem — a notification takes you straight to the right tab. The rest of the time? Silence. Your attention goes exactly where it’s needed, when it’s needed.

The hard parts, handled

VibeCrew takes care of everything that makes AI-generated code unreliable.

◆ Architecture before code

Vision, design system, tech stack, and architecture are established before any code is written. A phase gate enforces this — no shortcuts. Solid foundation from day one.

◆ Quality on autopilot

Tests, linting, type checking, build verification, code review, and security auditing run automatically. You don’t need to know what ESLint is — every feature meets production standards before reaching your main branch.

◆ Patterns that convert

Built-in UI and business pattern libraries teach agents what production-quality means. Forms get proper error states. Pricing pages use tiered anchoring. Onboarding follows proven conversion funnels.

◆ Tokens spent wisely

Worktree isolation keeps research tokens separate from your main session. MCP servers replace pasting docs. Zero-token hooks enforce rules without spending a single token. Forced compaction between features prevents context rot. Free and open source — works with Claude Pro, Max, or API.

How it works

Type slash commands, agents do the work, you get notified when needed. Here’s what’s under the hood.

Smart context management

Worktree isolation keeps research tokens separate. Forced compaction between features prevents context rot. MCP servers replace pasting docs. You never hit the context wall.

The Performance Coach

Every session gets a Vibe Score. The coach identifies waste, proposes a rule to prevent it, and writes it permanently with your approval. Each session more efficient than the last.

The Interrupt Protocol

Terminal stays silent during work. OS notifications fire only on: permission needed, task complete, critical error. One-click deep link to the exact tab.

Adapts to you

Run /profile — a 2-minute interview or pick a preset. Personalizes verbosity, autonomy, PR format, code comments, risk tolerance. The system meets you where you are.

Get started in minutes

Whether you’re starting fresh or bringing an existing codebase, VibeCrew guides you through every step.

✚

New project

  1. Install VibeCrew — clone and symlink into your project directory
  2. Run /setup — VibeCrew checks your environment and installs missing tools
  3. Run /profile — 2-minute interview or pick a preset (Founder, Builder, Explorer)
  4. Run /new-project — guided foundation: vision, design system, tech stack, architecture
  5. Run /new-feature "your first feature" — full development cycle starts
Quick Start Guide →
↗

Existing project

  1. Install VibeCrew — clone and symlink into your project root
  2. Run /setup — environment check and dependency installation
  3. Run /profile — set your experience level and preferences
  4. Run /onboard — Code Auditor analyzes your codebase, extracts conventions, generates CLAUDE.md
  5. Run /plan-features — define your backlog, then /new-feature to start building
