Plugin Structure

VibeCrew is a Claude Code plugin — an add-on that gives Claude Code new abilities. When you open a project with VibeCrew installed, Claude Code reads a manifest file and automatically loads agents, skills, hooks, scripts, MCP servers, and permissions. Everything lives inside the claude-plugin-vibe-crew/ directory.

■
What it is

A self-contained folder with a plugin.json manifest that registers agents, slash commands, hooks, scripts, and MCP servers — everything the system needs in one install.

✓
What problem it solves

Without a plugin, you'd manually configure each agent, permission rule, and automation script for every project. The plugin bundles everything into a single install.

Plugin Components

ComponentFile / DirectoryWhat It Does
Plugin Manifest .claude-plugin/plugin.json Entry point that Claude Code reads on startup. Registers every agent, skill, hook binding, and MCP server so they load automatically.
MCP Servers .mcp.json Configures external tool servers (Context7, Chrome DevTools, Playwright, and conditionally Semgrep, Sentry, Supabase, Stripe, Vercel, Figma) that give agents web search, browser control, and service integrations.
Permissions settings.json Allow/deny rules that control what agents can do without prompting. Allows file ops, npm scripts, and git; blocks sudo, force push, and destructive commands.
Hooks hooks/hooks.json Event bindings that map Claude Code lifecycle events (session start, tool use, stop) to bash scripts that enforce rules at zero token cost.
Scripts scripts/ Bash programs that handle mechanical work: state mutations, scoring, git operations, notifications, formatting, and project analysis.
Agents agents/ System prompt files that define each specialized AI agent's role, tools, constraints, and output format.
Skills skills/ Slash command definitions as SKILL.md files. Each contains YAML metadata and a workflow body that routes to the right agent(s).
Templates templates/ Project scaffolding templates, doc-site scaffold, and an MCP registry of additional servers that can be auto-discovered from TDR technology choices.
Tests tests/ BATS test suite that validates hook scripts, state management, and core plugin behavior.
