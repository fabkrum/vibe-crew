Companion Skills

Companion skills are third-party Claude Code skills that extend VibeCrew with specialized domain expertise — frontend aesthetics, framework best practices, database optimization, security analysis, and more. VibeCrew automatically recommends relevant skills after your TDR is approved, following the same pattern-matching approach as MCP server sync.

■
What they are

SKILL.md files published by official vendors (Anthropic, Vercel, Supabase, Cloudflare, Stripe) that inject domain-specific rules and patterns into Claude Code sessions. Unlike MCP servers (which provide tool access), skills provide knowledge and conventions — best practices, optimization rules, and design guidelines.

✓
What problem they solve

VibeCrew handles architecture, workflow orchestration, and code quality. But domain-specific expertise (React re-render optimization, Postgres query tuning, Core Web Vitals auditing) is better maintained by the technology vendors themselves. Companion skills bring that vendor expertise into VibeCrew sessions without bloating agent prompts.

Three Ways to Get Skills

▶
1. Auto-recommend (Registry)

After TDR approval, recommend-companion-skills.sh pattern-matches your technology choices against the curated registry (templates/companion-skills.json). If your TDR mentions "React" and "Supabase," it recommends React Best Practices, Web Design Guidelines, Frontend Design, and Supabase Postgres Best Practices.

⚠
2. Discovery (skills.sh)

For TDR technologies with no registry match (e.g., Prisma, Drizzle), VibeCrew searches the broader ecosystem in priority order: Anthropic skills → official vendor repos → skills.sh. Every discovered skill passes through a 5-gate quality check before being recommended.

✓
3. Manual (/install-skill)

Install any skill directly — GitHub repos, local paths, or company-internal repositories. Run /install-skill https://github.com/my-company/our-skills or /install-skill /path/to/local/skill. Safety validation runs automatically for remote sources.

5-Gate Quality Check

Every discovered skill (from skills.sh or manual install of remote sources) passes through validate-skill-safety.sh before being recommended or installed. All 5 gates must pass.

GateCheckReject If
1. Trusted Author Compare GitHub org against allowlist (Anthropic, Vercel, Cloudflare, Supabase, Stripe, Trail of Bits, Clerk, Hookdeck, Netlify, Prisma) Unknown org gets a warning flag (shown to user, not auto-rejected)
2. Repo Health GitHub API: stars, last commit date, license <20 stars OR no commits in 6 months OR no license
3. SKILL.md Scan Read SKILL.md content, check size and structure >15KB (bloated) or missing expected structure
4. Dangerous Patterns Grep for: rm -rf, curl|sh, eval, exec(, process.env reads of secrets, base64 decode, outbound fetch Any match = reject
5. Script Audit If skill has scripts/ directory, scan each file Network calls to non-GitHub URLs, file deletion outside project, env var exfiltration

Skills from trusted authors with a passing verdict are recommended directly. Skills from unknown authors with a passing verdict are recommended with a warning: "This skill is from an unverified author. Review it before installing."

The registry at templates/companion-skills.json contains pre-vetted skills from official vendors. These are always safe to recommend — no quality gate needed.

How VibeCrew Adapts

When companion skills are detected, VibeCrew agents adjust their behavior to avoid duplication and leverage the skill's expertise.

▶
Builder + Frontend Design

When Anthropic's frontend-design skill is installed, the Builder defers typography, color aesthetic, and motion choices to the skill. Design specs focus on component architecture, data flow, and business patterns instead. Wireframes remain unchanged (they're about layout, not aesthetics).

■
Detection mechanism

detect-companion-skill.sh checks ~/.claude/skills/ and .claude/skills/ for installed skill folders. Agents call this lightweight script inline before phases where skill overlap would occur.

Manual Installation

Use /install-skill to add any skill — including company-internal, private, or custom skills that aren't in the registry or on skills.sh.

Examples

CommandSource TypeQuality Gate
/install-skill vercel-labs/agent-skills --skill react-best-practices GitHub (public) Full validation
/install-skill https://github.com/my-company/internal-skills GitHub (private) Full validation (requires gh auth)
/install-skill /path/to/local/skill Local path (in project) Skipped (trusted)
/install-skill ~/company-skills/our-patterns Local path (outside project) Full validation

Installed skills are tracked in .vibecrew/config.json under companion_skills.manual with source, install timestamp, and safety verdict.

Companion Skills vs MCP Servers

Both extend VibeCrew, but they serve different purposes.

AspectCompanion SkillsMCP Servers
What they provide Knowledge, rules, conventions Tool access (APIs, browsers, databases)
Format SKILL.md files with guidelines JSON-RPC servers exposing tool endpoints
Runtime cost Context tokens (loaded into prompts) Process overhead (running servers)
Auth required Rarely (only for private GitHub repos) Often (API keys, tokens)
Discovery Registry + skills.sh Registry (mcp-registry.json)
Install mechanism npx skills add <source> Added to .mcp.json

Notes

⚠
No official backend skill

As of March 2026, no official vendor publishes a general backend development skill. VibeCrew's Tier 2 workflow (Builder agent, TDR boundaries, Context7 docs) covers backend development natively.

■
Trail of Bits for security

Trail of Bits (trailofbits/skills) offers 40+ professional security analysis skills. These are recommended manually for security-critical projects rather than auto-installed, as they significantly expand the agent's security analysis scope.
