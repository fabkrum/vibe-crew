Quick Start Guide

Get from zero to your first feature in under 10 minutes. This guide covers the essentials — see the full Setup Guide for advanced options.

Prerequisites

Make sure you have these installed:

  • Git 2.30+ — git --version
  • Node.js 18+ — node --version
  • jq 1.6+ — jq --version (install: brew install jq)
  • Claude Code — claude.ai/code

1. Install VibeCrew

Clone once, symlink to every project:

bashmkdir -p ~/claude-plugins && cd ~/claude-plugins
git clone https://github.com/fabkrum/vibe-crew.git
cd ~/projects/my-project
ln -s ~/claude-plugins/vibe-crew/claude-plugin-vibe-crew ./claude-plugin-vibe-crew

2. Run Setup

Start Claude Code with the plugin loaded and run the setup wizard:

bashclaude --plugin-dir ./claude-plugin-vibe-crew

Then inside Claude Code:

claude code/setup

The wizard verifies dependencies, detects your terminal, and creates the .vibecrew/ runtime directory.

3. Start a New Project

claude code/new-project

This runs the Tier 1 foundation — a sequential process that creates:

  1. VISION.md — What you're building and who it's for
  2. Design System — CSS tokens via the Design Discovery interview
  3. TDR — Technology Decision Record (researched by Stack Scout agent)
  4. Architecture Diagrams — 5 Mermaid diagrams covering your system
  5. Roadmap — Initial 5-8 feature backlog
  6. CLAUDE.md — Project rules for future sessions
This takes 15-30 minutes

The foundation is a one-time investment. After this, every feature session starts instantly because the architecture decisions are already made.

4. Build Your First Feature

claude code/new-feature "user-authentication"

This enters the Tier 2 feature cycle: Plan → UI Design → Code → Test → Review → Docs. The Builder agent handles implementation within the boundaries set by your TDR.

5. Wrap the Session

claude code/wrap

This runs the quality gate (tests, lint, build), calculates your Vibe Score, generates a session log, and commits your work.

What Just Happened?

You now have:

  • A complete project architecture (design system, TDR, diagrams)
  • A feature built with automated testing and code review
  • A Vibe Score tracking your development quality
  • Session logs and documentation auto-generated
