Architecture

Architecture Overview

VibeCrew is a system of specialized agents, deterministic hooks, and bash scripts that work together to enforce quality, manage attention, and continuously improve your workflow. This section explains how VibeCrew works under the hood.

New to coding?

You don't need to understand all of this to use VibeCrew — just type the slash commands and the system handles the rest. But if you're curious about what's happening behind the scenes, or want to troubleshoot an issue, these pages have the answers. Each section starts with a plain-English explanation before diving into technical details.
