The Problem & The Solution

Why VibeCrew Exists

AI-assisted development — "vibe coding" — has changed how software gets built. A single developer can now ship at the pace of a small team. But scaling this workflow quickly exposes serious gaps: sessions lose context, architecture decisions happen by accident, and you spend more time managing AI agents than building your product.

VibeCrew is a Claude Code plugin that fills those gaps. It wraps every project in a structured lifecycle — from vision and tech stack research through feature development, testing, code review, and documentation — orchestrated by 14 specialized AI agents. You describe what you want to build, and VibeCrew handles the how: enforcing architecture before code, running quality gates automatically, sending you a notification only when it actually needs your input, and learning from every session to get smarter over time. Whether you are a seasoned developer or a non-technical founder, VibeCrew adapts to you — not the other way around.

Problem

The Attention Bottleneck

When you run 5–15 concurrent Claude Code sessions, finished or blocked agents wait silently. You manually poll tabs to find which session needs you, destroying your focus every time. Your most valuable resource — your attention — is wasted on hunting.

→
Solution

The Interrupt Protocol

The terminal stays silent during normal work. When an agent needs you (permission blocked, task complete, critical error), it sends a native OS notification with a one-click deep link to the exact tab. You never poll again.

Problem

Token Waste & Context Exhaustion

Pasting docs into chat (+1,500 tokens), correcting vague prompts (+500 each), re-explaining context after /clear (+2,000). When the context window fills, you lose all accumulated understanding and start from zero.

→
Solution

The Performance Coach

Every session ends with a Vibe Score (0–100). The coach identifies token waste, proposes a concrete CLAUDE.md rule to prevent it, and — with your approval — permanently writes that rule. Each session is more efficient than the last.

Problem

Code Without Architecture

Jump straight into code and the AI picks the wrong state library, uses incompatible API patterns, and generates components that ignore your design system. You catch it three features in, when technical debt has compounded.

→
Solution

The Two-Tier Workflow

A phase gate blocks all source code writes until the project foundation is complete: vision, design system, tech stack decision, roadmap, and project rules. Architecture decisions are deliberate, not accidental.

Problem

One Size Fits Nobody

Most AI coding tools treat everyone the same. A non-technical founder gets the same commit messages, PR formats, and unexplained decisions as a senior developer. Beginners are overwhelmed. Experienced developers are slowed down by verbose explanations they don't need.

→
Solution

Adaptive User Profiles

Run /profile and VibeCrew adapts to you. A 2-minute interview (or pick a preset) personalizes every agent: message verbosity, autonomy level, PR format, code comments, gamification, and tech risk tolerance. As you grow, update your profile — the system evolves with you.

The Core Philosophy
Human attention is the bottleneck, not AI speed. VibeCrew is designed to maximize your focus time by minimizing interruptions, enforcing architecture before code, and turning every session into a learning opportunity.
