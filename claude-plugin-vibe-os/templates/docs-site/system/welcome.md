# Welcome to VibeOS

Your project dashboard powered by VibeOS. This site tracks your development progress, Vibe Scores, and feature delivery.

## First Session Checklist

1. **Set up** - Run `/setup` to verify your environment and initialize VibeOS
2. **Create foundation** - Run `/new-project` for a new project, or `/onboard` for an existing one
3. **Plan features** - Run `/plan-features` to define your feature backlog
4. **Start building** - Run `/new-feature "name"` to begin your first feature
5. **Wrap up** - Run `/wrap` when done to get your Vibe Score

## Command Quick Reference

| Phase | Command | What it does |
|-------|---------|-------------|
| Setup | `/setup` | Verify environment, initialize VibeOS |
| Setup | `/onboard` | Onboard an existing project |
| Foundation | `/new-project` | Create project foundation (VISION, design, TDR) |
| Planning | `/plan-features` | Define and prioritize feature backlog |
| Planning | `/idea "text"` | Quick-capture an idea to the backlog |
| Development | `/new-feature "name"` | Start a feature (plan, design, code, test, docs) |
| Development | `/run-backlog` | Auto-process next ready feature |
| Quality | `/check` | Run tests, build, lint, type-check |
| Session | `/wrap` | End session: score, logs, handoff, docs |
| Session | `/handoff` | Generate context transfer for next session |
| Info | `/status` | View current project state |
