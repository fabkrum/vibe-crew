Skills Reference

Every slash command maps to a skill — a SKILL.md file in the skills/ directory. Skills range from zero-cost script-only operations (like /idea and /status) to complex multi-agent orchestrations (like /new-project and /wrap). Use the category filters to browse all 33 skills.

■
What they are

SKILL.md files with YAML frontmatter (name, description, arguments) and a markdown body defining the full workflow: preconditions, steps, error handling, and agent routing. Some skills are script-only (zero tokens), others spin up single or multiple agents.

✓
What problem they solve

Skills turn complex multi-step workflows into single commands. Instead of writing a detailed prompt for "run tests, calculate score, generate docs, commit, and log session," you type /wrap and the skill definition handles every step, error path, and agent handoff.
