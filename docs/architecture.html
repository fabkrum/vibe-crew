How VibeCrew Works

VibeCrew is a system of interlocking parts: a plugin shell, specialized agents, lifecycle hooks, slash commands, bash scripts, and per-project runtime state. Each piece solves a specific problem that emerges when AI builds software autonomously.

Four Problems VibeCrew Solves

■
AI forgets rules mid-session

Hooks enforce constraints with bash scripts at zero token cost. The phase gate blocks code writes before architecture is decided. The quality gate catches build errors. No tokens spent, no rules forgotten.

■
Context windows fill up fast

Worktree agents isolate expensive research into separate contexts. Only the distilled output enters your main session — saving thousands of tokens and keeping the main context clean.

✓
No persistent memory across sessions

The .vibecrew/ state directory persists everything: which features are done, what phase you're in, quality trends, architecture diagrams, and cross-session handoffs.

▶
Manual workflows are error-prone

Slash commands encode expert workflows into single triggers. /wrap runs quality checks, scores your session, generates docs, and commits — all automatically, every time.
